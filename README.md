# homebrew-velocity

Homebrew tap for [Velocity](https://github.com/Limestone-Digital-Agents) tools by Limestone Digital.

## Install

```bash
brew install limestone-digital-agents/velocity/velocity-agent
```

Or tap first, then install:

```bash
brew tap limestone-digital-agents/velocity
brew install velocity-agent
```

## Formulas

| Formula | Description | Source |
|---|---|---|
| `velocity-agent` | Autonomous worker that picks up tracker tickets and dispatches them to an AI coding agent | [velocity-agent](https://github.com/Limestone-Digital-Agents/velocity-agent) |
